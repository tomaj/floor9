Two things on my mind

Last week I mentioned firstmate in a single paragraph. It deserves more. And then the internet had a week where someone rebuilt Adobe's whole suite as open source - which is worth a moment of thinking, wherever you sit.
01 Talk to one agent. Ship with a crew.

Running one coding agent is easy. Running five at once turns you into a tab-juggler: which terminal had the failing test, who's touching which file, what was I waiting for?

firstmate flips it. You talk to one agent - the first mate. It hires the crew, gives each agent its own clean copy of the code, watches them work, and only comes back when there's a real decision for you. The more I use it, the more impressed I am. It honestly feels like magic.

That's how Po Ruke was built at the HackAIton: several agents at once. One did the research, another built the dashboard, others took the remaining screens - parking, insurance, services. firstmate put it all together, and it did that really well.

The part I didn't expect: the specs it writes for its crew are excellent. Before an agent starts, the first mate hands it a clear brief - what to build, where it fits, how to check it's done. Good specs are half the job, and these are really good.

That's the shift: with very little human interaction, it produces things that are production quality - validated, tested, rebased on the latest code. My job became deciding what to build and what to merge.

02 Food for thought: software just became copyable

In early October, developer Brandon Thomas released ArtCraft: seven free, open-source apps written in Rust with Claude, each one a stand-in for an Adobe product.
PhotoCraft Photoshop
VectorCraft Illustrator
FilmCraft Premiere Pro
LightCraft Lightroom
EffectCraft · DesignCraft · PrintCraft After Effects · InDesign · Acrobat

Why he says it's legal: it's a clean-room rebuild. No Adobe code, written from scratch from public documentation and observed behavior. Copying how something behaves isn't copying the code.

Fair caveats: no one has independently checked that claim, patents are a separate question, and the apps are early alpha - the project's own roadmap puts them at roughly a quarter to a third of what a pro needs. Not a Photoshop killer. Yet.

The tool everyone is talking about

The same week, REA - "Reverse Engineer Anything" - blew up on GitHub. It plugs your coding agent (Claude Code, Codex, Cursor) into real reverse-engineering tools like Ghidra and Hopper. Point it at an app - a native binary, an Android APK, an Electron app, a website - and ask "how does this feature work?"

It doesn't hand you the original source code and it doesn't clone apps. It explains a feature, with evidence, so you can rebuild the idea in your own stack. Its own rule: recreate ideas and behavior, not copyrighted code or assets. (Thomas says ArtCraft didn't use REA itself - but it's the same idea.)

So what does it mean for us?

If anyone can study how a feature works and rebuild it in weeks, features stop being a moat.

What's left is what can't be copied: customers, data, trust - and how fast you move. A telco has plenty of the first three. The fourth is the one we keep working on.

Question for you: what would you rebuild if it took a week instead of a year? Reply - I'm genuinely curious.
